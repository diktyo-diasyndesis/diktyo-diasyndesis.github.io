# Δίκτυο Γραφείων Διασύνδεσης ΑΕΙ

Πιλοτική πρωτοβουλία του Γραφείου Διασύνδεσης του Πανεπιστημίου Δυτικής Μακεδονίας.
Κοινός χώρος των Γραφείων Διασύνδεσης των ελληνικών ΑΕΙ: κατάλογος γραφείων, δράσεις,
ανοιχτά σεμινάρια, δημόσιες ευκαιρίες, κλειστή συζήτηση και μηνιαίο Δελτίο του Δικτύου.

- Εγκαθίσταται σε κινητό και υπολογιστή (PWA).
- Είσοδος μόνο με ιδρυματικό email ελληνικού ΑΕΙ και έγκριση από διαχειριστή.
- Δεν αποθηκεύονται δεδομένα φοιτητών ή εργοδοτών.
- Δωρεάν φιλοξενία: GitHub Pages (εφαρμογή) και Supabase (βάση δεδομένων).

Χωρίς ρυθμίσεις στο `config.js`, η εφαρμογή ανοίγει σε **προεπισκόπηση** με ενδεικτικά δεδομένα.

---

## Εγκατάσταση βήμα βήμα (περίπου 20 λεπτά)

### Α. Βάση δεδομένων στο Supabase

1. Μπείτε στο **supabase.com** → *Start your project* → σύνδεση με τον λογαριασμό GitHub.
2. *New project*:
   - Name: `diktyo`
   - Database password: ένας δυνατός κωδικός (κρατήστε τον κάπου)
   - Region: **Central EU (Frankfurt)**
   - Plan: Free
3. Όταν ετοιμαστεί το project: αριστερά **SQL Editor** → *New query*. Ανοίξτε το αρχείο
   `supabase/schema.sql`, αντιγράψτε **όλο** το περιεχόμενο, επικολλήστε και πατήστε **Run**.
   Πρέπει να δείτε «Success».
4. Αριστερά **Authentication** → **Sign In / Providers** → **Email**:
   απενεργοποιήστε το **Confirm email** και πατήστε *Save*.
   (Την επιβεβαίωση των χρηστών την κάνει ο διαχειριστής με την έγκριση.)
5. **Project Settings** → **API**: κρατήστε το **Project URL** και το **anon public key**.

### Β. Εφαρμογή στο GitHub

1. Στο **github.com** πατήστε **+** (πάνω δεξιά) → *New repository*.
   - Repository name: `diktyo`
   - **Public**
   - *Create repository*
2. Στη σελίδα που ανοίγει πατήστε **uploading an existing file**.
   Σύρετε μέσα **όλα** τα αρχεία και τους φακέλους του zip (μαζί με τους φακέλους `icons` και `supabase`)
   και πατήστε *Commit changes*.
3. Ανοίξτε το αρχείο `config.js` στο GitHub, πατήστε το μολύβι (Edit) και βάλτε μέσα στα εισαγωγικά
   το Project URL και το anon key από το βήμα Α5. Πατήστε *Commit changes*.
4. **Settings** → **Pages** → Source: *Deploy from a branch* → Branch: `main`, φάκελος `/ (root)` → *Save*.
   Σε 1–2 λεπτά η εφαρμογή είναι διαθέσιμη στο:
   **https://eleytheriaxris1-create.github.io/diktyo/**
5. Πίσω στο Supabase → **Authentication** → **URL Configuration** → *Site URL*:
   `https://eleytheriaxris1-create.github.io/diktyo/` → *Save*.

### Γ. Πρώτη είσοδος και ορισμός διαχειριστή

1. Ανοίξτε την εφαρμογή → **Αίτηση πρόσβασης** με το ιδρυματικό σας email (`@uowm.gr`).
2. Στο Supabase → **SQL Editor** εκτελέστε (με το δικό σας email):
   ```sql
   update public.profiles set status = 'approved', is_admin = true
   where email = 'to-email-sas@uowm.gr';
   ```
3. Στην εφαρμογή πατήστε **Έλεγχος ξανά**. Είστε μέσα ως διαχειριστής.
4. Από τον **Λογαριασμό** συμπληρώστε τα στοιχεία του γραφείου και ανεβάστε το λογότυπο του ΠΔΜ.

### Δ. Εγκατάσταση στη συσκευή

- **Android / Chrome / Edge**: μενού ⋮ → *Εγκατάσταση εφαρμογής* ή *Προσθήκη στην αρχική οθόνη*.
- **iPhone / iPad (Safari)**: κουμπί Κοινοποίηση → *Προσθήκη στην οθόνη Αφετηρίας*.

## Καθημερινή διαχείριση

- **Νέοι χρήστες**: Λογαριασμός → *Διαχείριση χρηστών* → Έγκριση. Πριν εγκρίνετε, επιβεβαιώστε
  (π.χ. τηλεφωνικά) ότι το πρόσωπο ανήκει στο Γραφείο Διασύνδεσης του ιδρύματος.
- **Δελτίο**: Δελτίο → *Σύνταξη νέου δελτίου* → *Αυτόματη σύνταξη* → διορθώσεις → *Έγκριση*.
- **Νέο domain email** για κάποιο ίδρυμα (SQL Editor):
  ```sql
  update public.offices set domains = array_append(domains, 'neo-domain.gr') where id = 'uowm';
  ```

## Σημειώσεις

- Στο δωρεάν πλάνο του Supabase, αν το project μείνει 7 ημέρες χωρίς καμία χρήση, «παγώνει».
  Το ξαναξεκινάτε από το supabase.com με το κουμπί *Restore*.
- Το anon key είναι σχεδιασμένο να είναι δημόσιο. Η προστασία των δεδομένων γίνεται από τους
  κανόνες πρόσβασης της βάσης (Row Level Security) που ορίζει το `schema.sql`.
- Τα domains email των ιδρυμάτων στο `schema.sql` πρέπει να επιβεβαιωθούν.
